# Referências de Projetos e Repositórios GitHub

Lista de ferramentas, bibliotecas e referências essenciais do ecossistema de **AI Engineering**:

## Frameworks & SDKs
- [Model Context Protocol (MCP) SDKs](https://github.com/modelcontextprotocol) - SDKs oficiais para TypeScript, Python e Kotlin.
- [LangChain](https://github.com/langchain-ai/langchain) - Framework para desenvolvimento com LLMs.
- [LlamaIndex](https://github.com/run-llama/llama_index) - Framework focado em RAG e indexação de dados.

## Banco Vetorial (Vector Databases)
- [ChromaDB](https://github.com/chroma-core/chroma) - Vector DB open-source para embeddings.
- [Qdrant](https://github.com/qdrant/qdrant) - Motor de busca vetorial em Rust.
- [PGVector](https://github.com/pgvector/pgvector) - Extensão vetorial para PostgreSQL.

## Observabilidade & Evals
- [LangSmith](https://www.langchain.com/langsmith) - Plataforma de tracing e evals.
- [Arize Phoenix](https://github.com/Arize-ai/phoenix) - Observabilidade e avaliação de RAG em código aberto.
